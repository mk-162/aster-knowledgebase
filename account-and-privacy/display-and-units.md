# Display and units

Go to **Settings → Display & units** to choose how distances and speeds are
shown, which sport Aster leans toward for you by default, and how large the
app's text is.

## Metric or imperial

Toggle **Use imperial units** to show distances in miles and speed in mph.
Off shows kilometres and km/h. The screen shows a live preview as you
switch, using a marathon distance, so you can see exactly what changes.

This choice is saved to your account, not just this device, so setting your
phone to miles carries over to your tablet and the web app too. It also
changes how Aster's own notifications read: a distance-milestone
notification is written in each recipient's own choice of units, not the
units the person doing the activity happens to use. Two followers watching
the same ride, one on kilometres and one on miles, each get the notification
in their own units.

> **Good to know:** your distance and time are always recorded and worked
> out the same way underneath. This setting only changes how they're shown
> and described to you.

If you're not signed in, you can still set this for your own browsing; it's
remembered on this device.

## Sport preference

Choose whether Aster leans toward rides, runs, or both by default. This
option only appears once you're signed in.

| Choice | What it does |
|---|---|
| **Ride & Run** (default) | Shows everything; no lean either way. |
| **Ride** | Discover and the Go Live tab default to cycling. |
| **Run** | Discover and the Go Live tab default to running. |

This is a starting point, not a filter. An event or activity you've already
joined, followed, or belong to always stays visible, whatever you've set
here. It seeds what Discover shows first and the default on the
[Ride/Run chip](../for-athletes/free-rides.md) when you next start a Just
Ride.

## Text size

Choose **Standard**, **Large** or **Extra large** to make the app's text
easier to read. A preview line updates as you switch. This only changes
text size, not spacing, buttons or the map, so nothing else about the
layout moves.

Text size is set per device, not per account: you can have a different size
on your phone and your tablet, and it works even if you're not signed in.

## Good to know

- Units and sport preference are account-level, they follow you wherever
  you sign in.
- Text size is device-only. Changing it on one device doesn't change it
  anywhere else, and it's never synced to your account.
